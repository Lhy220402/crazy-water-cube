# 疯狂水立方 · 军 → 赢² → 水³ → Lec → OLD FIVE → 真通关了吗？

一个给同学玩的水主题 2048。手机浏览器打开就能玩，没有框架、没有网络请求、没有多余资源。
每次打开先看到「疯狂水立方」开场界面，点开始（或按 Enter / Space）进入棋局。
合出 OLD FIVE 只是**假通关**——真正的通关门道，藏在词条之间，留给你自己发现。

## 怎么玩

- 开场界面：最高分 + 已收录词条数；有存档时按钮变成「继续游戏」。点「玩法说明」直接看图鉴里的合成链。
- 手指在棋盘上滑（上/下/左/右），或按键盘方向键 / WASD。
- 两枚同级相碰就合成下一级，合成加分。
- 固定合成链：

| 材料 | 产物 | 得分 |
| --- | --- | --- |
| 军 ×2 | 赢² | +4 |
| 赢² ×2 | 水³ | +8 |
| 水³ ×2 | Lec | +16 |
| Lec ×2 | OLD FIVE | +32（假通关） |
| OLD FIVE ×2 | 随机词条（图鉴 +1） | +64 |
| 任意词条 ×2 | 再随机一条词条 | +64 |

- **特殊配方**（相撞即合，优先于普通判定，不分先后）：

| 材料 | 产物 | 得分 | 增益 |
| --- | --- | --- | --- |
| 隋 + 军 | 隋军 | +64 | 后续 8 步得分 ×2 |
| 隋·环 + 军 | 隋军·环 | +128 | 后续 12 步得分 ×3 |
| Li + Na | 李娜 | +128 | 后续 8 步得分 ×2 |

  另外还有**隐藏组合**：游戏内不会提示配方与产物，留给你自己试出来（剧透见交接文档）。
  多个增益乘算叠加；创建当步不生效也不消耗，从下一步开始倒数；棋盘上方徽章显示剩余步数。
- **假通关 / 真通关**：第一次合出 OLD FIVE 弹「真通关了吗？」（礼花照放）。真正通关的方式游戏内不写明，靠探索；两种通关都只弹一次，之后继续玩。
- **词条收集**：OLD FIVE 之后每次词条级合成都从池子里按权重随机抽一条。词条不用同名，任意两条都能合；稀有度（普通/稀有/传说）只影响显示和出现概率。允许重复，重复只累加出现次数。
- **词条池（14 条随机 + 4 条特殊产物）**：

| 词条 | 稀有度 | 说明 |
| --- | --- | --- |
| 隋 | 普通 | 带「+军」提示，隋系组合的起点 |
| 鳄鱼鳍 / 鳄食菌 | 稀有 / 传说 | 鳄鱼系列 |
| 隋·环 | 稀有 | 名字带圆圈，带「+军」提示 |
| 记 | 传说 | 隐藏组合材料（不显示配方提示） |
| 八一 / 红梅 / 金山 / 浮力 | 稀有 | 新增词条 |
| Li / Na | 稀有 | 两种元素，相撞 → 李娜 |
| 小明 / 燕子 / 豆包AI | 稀有 | 新增词条 |
| 隋军 / 隋军·环 / 李娜 / 记赢赢 | 特殊产物 | 触发即收录，不进随机池 |

  棋子上有稀有度角标（普/稀/传/特）；每条词条有自己的渐变配色，新增/调整配色改 `codex.ts` 的 `hue` / `hue2`。
- **解释卡**：首次抽到每条词条、首次触发每种特殊合成，都会弹出解释卡（文案在 `src/game/lore.ts`）。
- **未收录前图鉴是空白的**：词条页只显示「图鉴还是空白的」加一张问号悬念卡，不剧透名字、不显示总数；抽到/触发那一步才写入图鉴。特殊产物在合成链页首次触发前也打码。
- 图鉴两页：「合成链」（固定链 + 词条入口 + 特殊配方）、「词条」（已收集卡片）。收录跨局累积，重新开局不清空，撤销不回退。
- 撤销最多 20 步；最高分 / 棋局 / 图鉴自动存在浏览器本地，关掉再打开接着玩。
- 键盘：方向键 / WASD 移动，`Z` 撤销，`Esc` 关弹窗；开场界面按 Enter / Space 进入。
- 底栏「关于」：玩法简介 + Gitee / GitHub 仓库链接；「◐」按钮切换外观（跟随系统 → 浅色 → 深色，记住偏好）。

## 文件

- `疯狂水立方.html` —— **单文件版**，微信发给同学，下载后点开就能玩。
- `疯狂水立方-source.tar.gz` —— 完整源码，解压后 `npm install && npm run build`。
- `玩法说明.md` —— 本文件。
- `疯狂水立方-交接文档.md` —— 机制契约、数据结构、构建/测试、踩坑与可重写范围（换对话继续开发时先看它）。
- `疯狂水立方-新对话提示词.md` —— 可直接粘贴到新对话的启动提示词。

## 想加背景音乐 / 每步音效

接口已经留在 `src/ui/audio.ts`（当前是空实现，不创建 AudioContext、不加载资源）：

- `createAudio()` 返回 `AudioEngine`：`unlock / play / setEnabled / setVolume / startMusic / stopMusic / destroy`。
- `play()` 接受 cue 或 `AudioEvent`（cue + direction + merges + gained + variants），
  每个动作的播放点都已埋好：start / move / merge / special / collect / invalid / undo / restart / win / truewin / over。
- 实现时只改 `audio.ts`：在 `unlock()` 里创建 / 恢复 AudioContext，在 `play()` 里按 cue 播放。
- 单文件契约不能引外部音频：资源要内联 data URI，或用 WebAudio 现场合成。
- 音乐开关如果要记住，会需要第 5 个 localStorage key，先同步更新交接文档的存档契约。

## 想加新词条（最常做的事）

只改 `src/game/codex.ts` 里的 `CODEX_ENTRIES`，追加一项即可：

```ts
{ id: 'new-one', name: '新词条', rarity: 'rare', weight: 2, hue: 300, hue2: 330 /* 可选 */ },
```

- `id` 是存档身份，**定下来就别改**；`weight` 越小越难抽。
- `ring: true` 让名字带圆圈；`recipe` 在棋子角上显示配方提示。
- `hue` / `hue2` 是棋子与图鉴卡片的渐变双色相；不写则按池子顺序自动分配。
- 解释文案去 `src/game/lore.ts` 按 id 补一行。
- 加词条不会让正在进行的这局作废，也不用改 UI；图鉴总数会自动跟着变。

## 想加新特殊配方

改 `src/game/recipes.ts`：`PRODUCTS` 加产物（含增益与可选 `hue`），`RECIPES` 加配对，再去 `lore.ts` 补解释。
图鉴收录、棋子渲染、存档校验、合成链页全部自动跟随。

## 想加新等级（固定合成链）

只改 `src/game/config.ts` 里的 `TIERS` 数组，追加一项，其余自动跟随：
最后一项自动成为假通关等级与词条收集入口。存档带等级签名，改等级表后旧档自动作废。
注意 `liu` 这个 id 是 OLD FIVE 的存档身份（历史原因），改名不改 id。
