# 疯狂水立方 · 军 → 赢² → 水³ → Lec → OLD FIVE → 真通关了吗？

一个给同学玩的水主题 2048。手机浏览器打开就能玩，没有框架、没有网络请求、没有多余资源。
每次打开先看到「疯狂水立方」开场界面，点开始（或按 Enter / Space）进入棋局。
合出 OLD FIVE 只是**假通关**——真正的通关门道，藏在词条之间，留给你自己发现。

## 下载（v3.0.2）

- **单文件版**：下载 `疯狂水立方.html`（约 148.3 KB）——微信转发给同学，点开就能玩；无需联网、无需安装，`file://` 直接可跑。
- **在线版（GitHub Pages）**：[https://idealismo10.github.io/crazy-water-cube/](https://idealismo10.github.io/crazy-water-cube/)，内容与单文件版相同。
- **发行版**：[GitHub Releases](https://github.com/idealismo10/crazy-water-cube/releases) · [Gitee 发行版](https://gitee.com/idealismo10/crazy-water-cube/releases)（含单文件版、源码包、玩法说明、SHA256 校验和）。

## 怎么玩

- 开场界面：最高分 + 已收录词条数；有存档时按钮变成「继续游戏」。点「玩法说明」直接看图鉴里的合成链。
- 手指在棋盘上滑（上/下/左/右），或按键盘方向键 / WASD。
- 两枚同级相碰就合成下一级，合成加分；每次合成会播放一声猫叫音效，无路可走时播放一段失败音效。
- 固定合成链：

| 材料 | 产物 | 得分 |
| --- | --- | --- |
| 军 ×2 | 赢² | +4 |
| 赢² ×2 | 水³ | +8 |
| 水³ ×2 | Lec | +16 |
| Lec ×2 | OLD FIVE | +32（假通关） |
| OLD FIVE ×2 | 随机词条（图鉴 +1） | +64 |
| 任意词条 ×2 | 再随机一条词条 | +64 |
| 传奇 ×2 | 再随机一条传奇（图鉴 +1） | +512 |

  传奇是当前最高等级（rank 6），不能和普通等级 / 普通词条相合；获取第一枚传奇的方式属于隐藏内容，
  游戏内不会提示，这里不剧透。

- **特殊配方**（相撞即合，优先于普通判定，不分先后）：

| 材料 | 产物 | 得分 | 增益 |
| --- | --- | --- | --- |
| 隋 + 军 | 水军（v2.3 前叫「隋军」） | +64 | 后续 8 步得分 ×2 |
| 隋圆 + 军 | 隋军隋圆 | +128 | 后续 12 步得分 ×3 |
| 隋 + 钢 | 水缸 | +128 | 后续 8 步得分 ×2（和水军同一梯队） |
| Li + Na | 李娜 | +128 | 后续 8 步得分 ×2 |
| 彪 + 水³ | 妙 | +128 | 后续 10 步得分 ×2；这 10 步里每次移动都会在妙所在格飘爱心粒子（跟随妙移动） |

  另外还有**隐藏组合**：游戏内不会提示配方与产物，留给你自己试出来（剧透见交接文档）。
  多个增益乘算叠加；创建当步不生效也不消耗，从下一步开始倒数；棋盘上方徽章显示剩余步数。
- **假通关 / 真通关**：第一次合出 OLD FIVE 弹「真通关了吗？」（礼花照放）。真正通关的方式游戏内不写明，靠探索；两种通关都只弹一次，之后继续玩。
- **词条收集**：OLD FIVE 之后每次词条级合成都从池子里按权重随机抽一条。词条不用同名，任意两条都能合；稀有度只影响出现概率与光效，不影响配对。允许重复，重复只累加出现次数。
- **词条池（33 条随机 + 7 条特殊产物 + 8 条传奇，共 48 条）**：

| 词条 | 稀有度 | 权重 | 说明 |
| --- | --- | --- | --- |
| 隋 | 稀有 | 6 | 带「+军」提示，隋系组合的起点（权重最高的常客） |
| 鳄鱼鳍 / 隋圆 | 稀有 | 3 / 2 | 隋圆棋子带圆环，带「+军」提示 |
| 鳄食菌 / 记 | 传说 | 1.2 / 0.8 | 记是隐藏组合材料（不显示配方提示） |
| 八一 / 红梅 / 金山 / 浮力 / Li / Na / 小明 / 燕子 / 豆包AI | 稀有 | 2 | 老词条 |
| 彪 / 会成 / 🌧️ | 稀有 | 2 | v2.2 新增；彪带「+水³」提示 |
| 钢 / 威海 / 钉剑 / 君竹 | 稀有 | 2 | v2.3 新增；钢带「+隋」提示 |
| 成龙 / 霸天 / 能 / 赵一鸣 / 塑料袋 | 稀有 | 2 | v2.4 新增 |
| 左轮 / 鱼籽 / 何思 | 稀有 | 2 | v2.5 新增 |
| 煤灰 / 昭君 / 小风 | 传说 | 1 | v3.0.1 修正：不是传奇，回到普通抽取池 |
| 象郡 | 稀有 | 2 | v3.0.1 修正：按最初设定为稀有 |
| 水军 / 隋军隋圆 / 水缸 / 李娜 / 记赢赢 / 妙 / 记会成 | 特殊产物 | — | 触发即收录，不进随机池；最后一条依赖隐藏配方 |
| 传奇（8 条） | 传奇 | 均匀 | v3.0 新增，当前最高等级；获取方式属于隐藏内容，游戏内不提示 |

  游戏内**不再有「普通」词条**：原来的「普通」全部升为稀有，抽取权重不变。
  棋子上有稀有度角标（稀/传/奇/特）；全部词条使用低饱和水彩玻璃色板，
  稀有带一道很细的静态银白边光，传说带香槟金细边与很轻的呼吸暖光（没有旋转/扫光/闪点），
  传奇用 OLD FIVE 同款金虹材质 + 金色光晕 + 慢速流光；记赢赢也换成同款金虹材质。
  v3.0.1 修正：煤灰 / 昭君 / 小风是传说、象郡是稀有，它们不再进传奇池与传奇分区。
  每条词条有自己的渐变配色，新增/调整配色改 `codex.ts` 的 `hue` / `hue2`。
  「隋圆」在图鉴与配方文本里写全名，棋子仍画一圈「隋」；特殊产物「隋军隋圆」内部 id 仍是 `sui-jun-ring`。
- **解释卡**：首次抽到有文案的词条、首次触发特殊合成，都会弹出解释卡（文案在 `src/game/lore.ts`）。
  「隋」「李娜」按用户要求去掉了说明：首次收录不弹卡，图鉴卡片也不显示说明区。
- **未收录前图鉴是空白的**：词条页只显示「图鉴还是空白的」加一张问号悬念卡，不剧透名字、不显示总数；
  但会显示一条**收集进度条**（只有比例，不写 x/y）。抽到/触发那一步才写入图鉴，特殊产物在合成链页首次触发前也打码。
- 图鉴两页：「合成链」（固定链 + 词条入口 + 特殊配方）、「词条」（收集进度条 + 已收集卡片）。
  普通词条下方是独立的「传奇」分区（传奇未收录前同样只显示问号卡）。
  全部收齐后，进度条满格、标题显示「共 48 条」，下方出现「未完待续」。收录跨局累积，重新开局不清空，撤销不回退。
- 撤销最多 20 步；最高分 / 棋局 / 图鉴自动存在浏览器本地，关掉再打开接着玩。
- 从 v3.0.0 升级时，旧存档里被误标成传奇的方块会**随机替换**为当前正确的传奇；
  最高分、分数、步数、通关、增益与图鉴收录（包括这 4 条现在合法的传说 / 稀有记录）都会保留。
- **版本更新提示**：更新到新版本后第一次进入游戏会弹一次「版本已更新」，只显示版本号变化
  （如 `v3.0.1 → v3.0.2`）；新玩家不弹，同一版本不会重复弹。记录存在 `jun2048.version`。
- 底栏「🔊 / 🔇」按钮开关合成音效与失败音效，偏好会被记住（`jun2048.sound`）；「◐」按钮切换外观
  （跟随系统 → 浅色 → 深色，记住偏好）。
- **关于**：入口收在图鉴抽屉底部（低频功能，避免误触），内容是玩法简介 + Gitee / GitHub 两个仓库链接；
  「在线玩」按钮已去掉（发给同学的本来就是 GitHub Pages 在线版）。
- 网站图标：三个水滴（Noto Emoji）摆成正三角、透明底，内联 SVG + PNG 兜底，不引外部图片。
- 键盘：方向键 / WASD 移动，`Z` 撤销，`Esc` 关弹窗；开场界面按 Enter / Space 进入。

## 音频（合成音效 v2.2.2 · 失败音效 v2.4.1）

- 合成音效：用户提供的微信语音里的**第二声猫叫**（1.15s–2.05s），已降噪（ffmpeg `afftdn` + 高通）、
  响度归一化，转成单声道 mp3，再 base64 内联进 `src/ui/merge-sfx.ts`。v2.4.1 没有改动这段音源。
- 失败音效（v2.4.1，2026-11-22 热更新加强）：用户提供的「标准录音 1.mp3」——先解码成无损 wav
  （绕开源文件损坏的首帧），去掉开头约 0.56s 静音/底噪，做 70Hz 高通 + 14kHz 低通、`afftdn` 降噪、
  `loudnorm` 归一化到 **-14 LUFS**（比合成音效的 -18 响约 4 dB）、首尾淡入淡出，
  再转成 44.1kHz 单声道 64kbps mp3 内联进 `src/ui/over-sfx.ts`；播放增益 1.0，比合成猫叫更突出。
- 播放：点「开始合成 / 继续游戏」时 `unlock()` 创建 AudioContext 并解码；合成后播放
  （merge / special / win / truewin 用不同音高），无路可走（over）播放独立的失败音效；
  普通移动、无效移动、撤销保持安静。失败音效每个死局只播一次，重开 / 撤销后复位。
- **互斥**：失败音效出现时会先把还在响的合成猫叫静音停掉，两段声音不会同时播放；
  本步如果已经判负，也不再播合成 cue。新的合成音效开始时会把失败音效的尾音停掉。
- 单文件契约：音频是 data URI，不引外部资源；声音开关存 `jun2048.sound`（第 5 个 localStorage key，`on`/`off`，缺省开）。
- 底栏「🔊 / 🔇」按钮切换 `audio.setEnabled()`，按钮状态与存档同步；音量本身不持久化。
- 重新处理：合成音效 `node scripts/audio.mjs <源音频> [起始秒] [结束秒]`（默认 1.15–2.05）；
  失败音效 `node scripts/audio.mjs over <源音频> [起始秒] [结束秒]`（默认 0.56–2.80）。
- 以后要加背景音乐：在 `audio.ts` 的 `unlock()` 里加载 loop；音乐开关若要持久化，
  先同步更新交接文档的存档契约再加 key。
- v2.3 曾尝试把猫叫剪成三段并做升降调，用户试听不满意，已完整回滚到上面这套 v2.2.2 实现；
  以后再动音效，先给试听方案、用户点头再替换。

## 想加新词条（最常做的事）

只改 `src/game/codex.ts` 里的 `CODEX_ENTRIES`，追加一项即可：

```ts
{ id: 'new-one', name: '新词条', rarity: 'rare', weight: 2, hue: 300, hue2: 330 /* 可选 */ },
```

- `id` 是存档身份，**定下来就别改**；`weight` 越小越难抽。
- `ring: true` 让名字带圆圈；`recipe` 在棋子角上显示配方提示。
- `hue` / `hue2` 是棋子与图鉴卡片的渐变双色相；不写则按池子顺序自动分配。
- 解释文案去 `src/game/lore.ts` 按 id 补一行；不写就是「没有解释」（不弹解释卡）。
- 加词条不会让正在进行的这局作废，也不用改 UI；图鉴总数会自动跟着变。
- 传奇词条不进 `CODEX_ENTRIES`，改 `MYTH_ENTRIES`（8 条独立池，只从隐藏组合抽取，图鉴单独分区）。

## 想加新特殊配方

改 `src/game/recipes.ts`：`PRODUCTS` 加产物（含增益与可选 `hue`），`RECIPES` 加配对，再去 `lore.ts` 补解释。
图鉴收录、棋子渲染、存档校验、合成链页全部自动跟随。
「妙」的爱心粒子是表现层：`buff.id === 'miao'` 时，`app.ts` 先记录移动前的妙，再按滑动的落格调用
`board.heartBurst(cells)`，爱心就跟着妙走到哪儿出现在哪儿，不改规则。

## 想加新等级（固定合成链）

只改 `src/game/config.ts` 里的 `TIERS` 数组，追加一项，其余自动跟随：
最后一项自动成为假通关等级与词条收集入口。存档带等级签名，改等级表后旧档自动作废。
注意 `liu` 这个 id 是 OLD FIVE 的存档身份（历史原因），改名不改 id。

## 待补充 / 已知取舍

- 真机浏览器目视检查（当前环境没有浏览器，未做）。
- 图鉴进度条：未集齐时只显示比例，不显示总数（保留旧悬念规则）；集齐后才显示「共 48 条」与「未完待续」。
  从旧版本升上来的玩家，图鉴会从「已集齐」重新显示未集齐，等新词条收齐后才会再次出现「未完待续」。
- 「隋」「李娜」没有解释文案是用户明确要求，不是漏写；以后要加回来只改 `lore.ts`。
- 爱心粒子跟随棋盘上的「妙」：在妙当前所在格生成；如果这步把妙合掉了，就落在合成后的格子。
  不额外改存档字段（增益本身已写进 v3 存档）。
- 传奇是全屏「现世」弹层：抽到时会暂停棋盘输入，直到点「继续合成」；这是刻意放大的节奏。
  传奇只能通过隐藏组合获得，图鉴总数（48）包含 8 条传奇，没解锁隐藏路的玩家会长期停在未集齐，属预期。
- v3.0.0 / v3.0.1 的传奇视觉 / 全屏动效只做了自动化结构验证，**没有做真机目视回归**。
- v3.0.1 只修正词条稀有度与图鉴分区归属（煤灰 / 昭君 / 小风 → 传说，象郡 → 稀有），
  传奇池从 12 条缩到 8 条；机制、存档与音源未动。
- v3.0.2 增加 v3.0.0 旧档迁移：只把旧存档 rank 6 上那 4 个误标传奇随机换成正确传奇，
  最高分、分数、步数、通关、增益、图鉴收录都保留；迁移后立刻回写，之后不再变化。
- 两个仓库已设为公开；GitHub Pages 在线版随版本刷新。
