# 疯狂水立方 · 重写设计（2026-11-21）

> 基于 docs/交接文档.md 的契约层重写。用户已确认三个关键决策（见下）。
> 本文档是新契约的事实来源；实现完成后 docs/交接文档.md 同步更新。

## 意图

把「2048 · 军 → 刘 No.5」改版为品牌游戏「疯狂水立方」：水主题视觉、假通关/真通关双层目标、
带稀有度的词条池与跨级特殊配方、增益系统、词条解释框架、关于菜单、深色模式手动切换。
机制骨架（4×4、滑动合成、单步不连锁、撤销 20、三 key 存档、图鉴悬念）不变。

## 用户拍板的决策

1. 仓库链接：先用占位（集中在 `src/game/meta.ts`，用户之后只改这一个文件）。
2. 「相连」= 2048 式相撞合成（滑动时碰撞触发），不做相邻自动合成，单步不连锁。
3. 词条之间保持旧规则：**任意两条词条（rank=codexRank）都能合**，结果从全池加权随机抽一条（+64）。
   稀有度只影响显示与抽取概率，不影响配对。

## 我的决定（用户授权「效果自己想」，可否决）

- 增益：隋军=后续 8 步得分×2；隋军·环=后续 12 步×3；记赢赢=真通关+本局永久×2。
  多个增益乘算叠加；创建当步不消耗步数、从下一步开始计数；HUD 徽章显示剩余步数。
- 特殊产物分数：隋军 +64、隋军·环 +128、记赢赢 +256（再乘当前增益）。
- 特殊产物方块也是词条级：可与任意词条方块继续合成（被消耗时增益已生效，不撤销）。
- 抽取权重：隋 6 / 鳄鱼鳍 3 / 隋·环 2 / 鳄食菌 1.2 / 记 0.8（普通≈46%，传说合计≈15%）。
- 旧词条池（彪！/会成！/🌧️！/食菌！）移除；旧收录记录按 id 过滤自动清空；
  含未知 variant 的旧棋局存档判坏档开新局（等级签名不变，仍是 jun|win|water|lec|liu）。
- 假通关：首次合出 OLD FIVE → won=true 持久化，弹「真通关了吗？」（礼花照放，不重复弹）。
  真通关：首次合出 记赢赢 → trueWon=true 持久化，更隆重庆祝；之后继续玩不重复弹。
- 解释框架：`src/game/lore.ts` 按 id 存文案（词条 5 条 + 特殊合成 3 条），先占位。
  首次抽到词条 / 首次触发特殊合成 → 弹解释卡；图鉴卡片也显示该文案。
- 稀有度可视化：词条方块稀有度描边 + 角标（普/稀/传）；隋/隋·环/记 显示配方提示（+军/+赢²）；
  圈隋用 CSS 圆环包住「隋」字。图鉴合成链页列出全部特殊配方。
- 深色模式：prefers-color-scheme 全套 token + 手动三态切换（自动/浅/深，存 jun2048.theme）。
- 关于：底栏「关于」→ 弹层（简介 + Gitee/GitHub 链接，新窗口打开）。
- 单文件自检放宽为「无外部资源」：允许指向 gitee.com / github.com 的 <a> 导航链接。
- pack 产物改名：疯狂水立方.html / 疯狂水立方-source.tar.gz；旧发布文件不删除。

## 合成体系（新契约）

固定链：军 ×2→赢²(+4) ×2→水³(+8) ×2→Lec(+16) ×2→OLD FIVE(+32，假通关)。
OLD FIVE ×2 → 全池随机词条(+64)；任意词条 ×2 → 全池随机词条(+64)。
特殊配方（相撞即合，优先于普通判定，unordered）：
- 隋 + 军 → 隋军(+64，增益×2/8步)
- 隋·环 + 军 → 隋军·环(+128，增益×3/12步)
- 记 + 赢² → 记赢赢(+256，真通关，永久×2)

## 数据结构变更

- Tile 不变（id/rank/variant）；特殊产物也用 variant 表达。
- GameState 增加 `trueWon: boolean`、`buffs: Buff[]`（{id,label,mult,movesLeft}，-1=永久）。
- MoveResult 增加 `justTrueWon`；Merge.variant 覆盖特殊产物；codexDraws 仍只报随机抽取。
- SavedGame v3：v2 字段 + trueWon + buffs；deserialize 兼容 v1/v2/v3；
  variant 必须存在于当前池或特殊产物表，否则坏档。
- canMove / move 的配对判定改为 tile 级：先查配方，再查同级（词条级任意配对）。
- 存档 key 不变：jun2048 / jun2048.best / jun2048.codex；新增 jun2048.theme。
